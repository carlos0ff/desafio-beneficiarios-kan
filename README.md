# Cadastro de beneficiários — desafio Kan

**Status: planejamento — implementação ainda não iniciada.**

Repositório de estudo de [José Carlos](https://github.com/carlos0ff), organizado a partir da [seleção de desafios de Matheus Leandro](https://www.matheusleandro.com.br/desafios).

## Objetivo

Desenvolver uma API de cadastro de beneficiários e documentos conforme a proposta identificada como “Empresa Kan” na plataforma.

## Escopo do desafio

- Cadastrar beneficiário e documentos em um mesmo fluxo.
- Listar os beneficiários existentes.
- Consultar documentos pelo identificador do beneficiário.
- Atualizar os dados de cadastro.
- Remover um beneficiário.
- Gravar os dados em banco relacional.
- Explicar a solução, o build e a execução no README.

## Tecnologias exigidas e opções

A proposta exige Java e Spring Boot. O banco relacional pode ser escolhido pelo desenvolvedor; H2 e Derby aparecem como alternativas embarcadas. Versões e ferramenta de build ainda serão definidas.

## Critérios de conclusão

- [ ] Definir modelo e relacionamento dos documentos.
- [ ] Implementar persistência e operações REST.
- [ ] Validar entradas e tratar registros inexistentes.
- [ ] Testar cadastro conjunto, consultas, atualização e exclusão.
- [ ] Documentar decisões e comandos reproduzíveis.
